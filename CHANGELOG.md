# История изменений

Формат основан на Keep a Changelog. Версии проекта следуют принятой для TMC StaffWork схеме.

## 0.1 — 2026-09-11

### Добавлено

- управление сотрудниками по UUID, внутренние ранги и отключение учётных записей;
- рабочие сессии, шесть статусов, история интервалов и календарная статистика;
- YAML, SQLite, H2, MySQL/MariaDB, схема версии 1 и индексы;
- команды `/staffwork` и `/sw`, tab completion и иерархия permissions;
- Folia-aware слой глобального и entity scheduling;
- кешируемое расширение PlaceholderAPI `tmcstaff`;
- безопасная отключаемая Telegram-интеграция с polling и привязкой;
- русская конфигурация, локализация и документация;
- тесты, Spotless, Checkstyle и GitHub Actions для Java 17/21.

### Ограничения

- MySQL/MariaDB требуют проверки с отдельным сервером БД;
- перенос данных между типами хранилища и межсерверная синхронизация событий отложены.

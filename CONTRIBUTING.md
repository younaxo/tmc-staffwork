# Участие в разработке

Спасибо за интерес к TMC StaffWork.

1. Создайте Issue с описанием задачи или ошибки.
2. Создайте ветку от актуальной `main`.
3. Используйте Java 17-совместимый код, не добавляйте NMS и блокирующие Bukkit-вызовы.
4. Пользовательские тексты пишите на русском, идентификаторы Java — на английском.
5. Выполните `./gradlew spotlessApply build`.
6. Убедитесь, что в diff нет токенов, паролей, БД, IDE-файлов и результатов сборки.
7. Создайте Pull Request с причинами изменения и результатами проверок.

Коммиты должны быть небольшими, законченными и иметь осмысленные русские сообщения. Исправление логики должно сопровождаться регрессионным тестом.
